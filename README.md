# kino_check
Веб-приложение для фиксирования просмотра фильмов и совместного выбора через рулетку.

## Возможности
- Каталог фильмов с фильтрацией и оценками (`movies.html`, `rating.html`)
- Колесо фортуны / рулетка для случайного выбора фильма (`index.html`)
- Добавление и импорт фильмов через форму или CSV (`add.html`)
- 🤖 **Telegram-бот (Serverless)** для добавления фильмов прямо из группового чата (см. [Инструкцию по запуску](docs/TELEGRAM_BOT_SETUP.md))
